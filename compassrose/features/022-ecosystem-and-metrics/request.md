# Request: Ecosystem and Metrics

I want CompassRose to eventually support a broader ecosystem.

Future capabilities may include:

- CI integration
- multiple adapters
- provider-specific adapters when justified
- cost tracking
- usage limits
- metrics
- team workflows
- audit reports

These features should not complicate the MVP.
They should be added only after the core deterministic workflow works.

CompassRose should remain small, provider-independent, and documentation-first.
