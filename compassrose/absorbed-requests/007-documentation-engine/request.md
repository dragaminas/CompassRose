# Request: Documentation Engine

I want CompassRose to maintain project documentation as the primary user interface.

The documentation engine should support creating and updating CompassRose documentation files from structured project knowledge.

It should support:

- generating feature documentation
- generating architecture drafts
- generating project state documentation
- keeping documentation editable by humans
- avoiding unnecessary rewrites
- preserving useful manual edits when possible

The documentation engine should work with the feature request and formalization flow.

Documentation should remain the source of truth for CompassRose, not a secondary artifact.
