# CompassRose Roadmap

## Vision

Create a deterministic software development orchestration system capable of transforming human intent into reviewed software through iterative planning, implementation and validation.

CompassRose must be capable of developing CompassRose.

---

# Foundation

Status: Planned

Goals:

* Establish project identity
* Define architecture
* Define documentation model
* Define user experience model
* Define architectural decisions
* Create initial repository structure

Success Criteria:

* SAD exists
* ADR exists
* UX specification exists
* Documentation model exists
* Initial roadmap exists

---

# Project Understanding

Status: Planned

Goals:

* Analyze existing repositories
* Detect languages and frameworks
* Detect build systems
* Detect test systems
* Detect repository structure
* Build initial project state

Success Criteria:

* CompassRose can initialize from an existing repository
* CompassRose can initialize from an empty repository
* Initial project state is generated automatically

---

# Documentation Engine

Status: Planned

Goals:

* Generate roadmap from human language
* Generate feature definitions
* Generate architecture drafts
* Generate project state documentation
* Keep generated documentation synchronized with repository reality

Success Criteria:

* User can describe a project in plain language
* CompassRose generates initial project documentation
* Documentation remains editable by humans

---

# Feature-Centric Planning

Status: Planned

Goals:

* Organize project knowledge around features
* Generate tasks from feature state
* Limit planning scope to relevant features
* Reduce context size

Success Criteria:

* Planning operates at feature level
* Tasks are generated on demand
* Long-lived task backlogs are unnecessary

---

# Deterministic Orchestration

Status: Planned

Goals:

* Execute planning loop
* Execute implementation loop
* Execute review loop
* Manage workflow state
* Recover from failures

Success Criteria:

* Planner can generate next task
* Implementer can execute task
* Reviewer can approve or reject task
* Workflow state is persisted

Status: Planned

Goals:

* Support local models
* Support remote models
* Support provider-independent execution

Success Criteria:

* Local and remote execution are supported
