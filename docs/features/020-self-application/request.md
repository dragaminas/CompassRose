# Request: Self Application

I want CompassRose to use its own workflow to develop CompassRose.

The CompassRose repository should follow CompassRose conventions.

That means:

- features live under `docs/features/`
- feature requests begin with `request.md`
- formalized features include `feature.md`, `architecture.md`, and `state.md`
- tasks are generated one at a time
- Git diff is used for review
- documentation remains the primary interface

CompassRose should become the reference implementation of its own methodology.
