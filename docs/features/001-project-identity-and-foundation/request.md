# Request: Project Identity and Foundation

I want CompassRose to establish its basic project identity and repository foundation.

CompassRose is a CLI-first TypeScript application for deterministic AI-assisted software development orchestration.

This feature should ensure that the repository has the minimum structure and documentation needed to become a CompassRose project.

It should cover:

- project identity
- initial repository structure
- documentation root
- source root
- contracts root
- basic package setup expectations
- Linux and Windows compatibility expectations

This feature should not implement orchestration yet.
It should only create the foundation that later features can rely on.
