## Goal
Update runtime preflight so enabled planner, implementer, and reviewer roles accept only the configured generic external_cli adapter, while preserving existing missing-adapter, execution-mode, role-enabled, git-policy, and valid no-task behavior.

## First Executable Step
Add a failing test in tests/main.test.ts that defines an additional adapter entry, points an enabled implementer role at that defined non-external adapter, and asserts main([], ...) returns exit code 1 with roles.implementer.adapter and runtime preflight diagnostics.
